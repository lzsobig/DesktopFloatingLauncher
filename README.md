# DesktopFloatingLauncher (桌面极速悬浮启动器)

<p align="center">
  <b>一款优雅、极轻量、全盘毫秒级响应的 Windows 桌面悬浮启动器</b><br>
  <i>Quiet Luxury 设计风格 · 纯原生 WPF · 单文件无第三方依赖 · 系统级快捷索引</i>
</p>

---

## 📸 项目特性

- ⚡ **全局唤醒与即开即用**：全局默认热键 `Alt + Space` 秒级呼出与收起，支持无缝记忆窗口拖拽坐标与置顶切换。
- 🔍 **全盘深度索引与智能去重**：
  - 自动扫描桌面（含子文件夹目录）、公共桌面、用户与系统开始菜单全层级、快速启动栏与任务栏固定项；
  - 接入 Windows 注册表标准应用库（`App Paths`）与网页快捷方式（`.url`）；
  - 智能过滤垃圾卸载脚本（`Uninstall`、`Readme`、`帮助文档`），保持收录结果干净利落。
- 🔤 **拼音首字母极速搜索**：支持拼音缩写（如 `txhy` ➔ 腾讯会议、`wx` ➔ 微信、`wps` ➔ WPS Office），随键入随匹配，高亮命中字符。
- 🧮 **即时算式计算器**：直接在搜索栏输入数学表达式（例如 `1024*768` 或 `(1+0.05)^10`），实时求值，回车直接一键复制到剪贴板。
- 🎨 **优雅简奢视觉设计 (Quiet Luxury)**：
  - 16px 完美对称圆角外壳与精致微弥散阴影；
  - 莫兰迪低饱和度色彩点缀，像素级统一网格对齐，彻底消除系统原生刺眼虚线框；
  - 自适应 2 列宽屏常用应用卡片，杜绝文字缩减截断。
- 🪶 **单文件零依赖编译**：纯 C# WPF 原生编写，无需安装体积庞大的开发套件或第三方运行时，系统内置 `csc.exe` 即可毫秒级单文件编译出绿色免安装程序。

## 🚀 快速开始

### 方式一：直接运行已编译的程序
从 Releases 下载或直接使用编译生成的 `桌面极速悬浮窗.exe`，双击启动即可在后台运行。

### 方式二：一键脚本编译（推荐）
本项目无需安装 Visual Studio，直接利用 Windows 系统内置的 .NET Framework 编译器：

1. 双击运行根目录下的 `build.bat`；
2. 编译成功后将在 `bin/` 目录下生成 `桌面极速悬浮窗.exe`。

### 方式三：使用 .NET CLI 编译
如果你已安装 .NET SDK：
```bash
dotnet build -c Release
```

## ⌨️ 常用快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Alt + Space` | 全局呼出 / 隐藏启动器窗口 |
| `Enter` | 立即启动当前选中的项目 / 复制计算器结果 |
| `↑` / `↓` | 在搜索匹配结果列表中自由切换高亮项 |
| `Esc` | 清空当前搜索输入 / 最小化至后台 |
| `Ctrl + 1~8` | 极速触发快捷栏对应序号的常用应用 |

## ⚙️ 配置文件与持久化

启动器会自动在系统漫游配置目录中维护用户数据：
- **配置文件路径**：`%APPDATA%\DesktopFloatingLauncher\config.txt`
- **保存项目**：
  - `WindowLeft` / `WindowTop`：上次停留屏幕坐标
  - `IsTopmost`：窗口是否固定最前端置顶
  - `CustomApp`：用户通过右键或拖拽添加的自定义快捷软件与参数
